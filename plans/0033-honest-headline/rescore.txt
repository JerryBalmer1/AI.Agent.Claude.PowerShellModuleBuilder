THE DEFECT
----------
Four RequiresBuild assertions read output/<Name>/, which is .gitignore'd and so
absent from any clone that has not been built.  The scoring protocol said
"score from a fresh clone" and did not say to build it.  Run 007's conformance
clone was therefore never built, and those four assertions graded the absence of
a directory rather than the module.

THE REPAIR
----------
The conformance clone is BUILT before it is scored.  The target's OWN default
build is invoked — no task name is assumed, because a non-house-style build file
is one of the things being graded (run 007's first shot declares
ValidateSet('Clean','Build','Test','All') and has no '.' task, so a wrapper that
hard-codes `-Task .` fails the build of exactly the commits it must grade).
A red build stops the scoring, per HARNESS.md step 3.
