## Why

**Three fresh clones, not one shared tree.** Run 005's F-7 recorded a race —
`build.ps1`'s `Clean` deleting `output/` while the `RequiresBuild` tag read it,
producing a false 51/56 — and concluded that isolation is the method. This pass
applied it. It costs about 50 seconds a round and it is worth it: the numbers are
now numbers about the artifact rather than about the schedule.

The same lesson then bit again one level up, inside `verify.ps1`: two builds run
in **one PowerShell session** left the module imported from the first clone's
`output/`, and the second clone's quality assertions graded the wrong module — 19
failures that vanished when each build got its own process. Isolating the working
tree is not enough if the session is shared. That is now in the script with the
reason beside it.

**The oracle was not edited, though it is wrong about itself.** `cases.md` case
12 justifies the four repo nodes by saying pipeline YAML references them; nothing
references `repo:consumer-app`, which has in-degree zero in the oracle. The rule
that produces exactly four is *referenced **or** hosts a definition*, and it still
satisfies case 12's actual test. Per `producer-contract`, the oracle is right
until a decision says otherwise: this is F-2, recorded with the mechanism, and
`evals/` was not touched.

**The prompt's leak was flagged rather than exploited.** Task 7 states runs 004
and 005's first-shot mechanisms and counts, and the prompt is inside the Phase 1
allowlist. It was declared before any code was written and deliberately not acted
on. The four conventions were chosen from the schema and `producer-contract`
alone, and three of the four were chosen wrongly — which is weak evidence that the
leak did not steer, and is stated as weak in the run record rather than as
exoneration.

**The acceptance assertion was left exactly as written.** Its whole-document
"does not match either prior session id" check went red on a draft that quoted
both predecessors' ids in order to prove it differed from them. Changing the
assertion would have been the easy fix and the wrong one; the record was
rewritten instead, and the limit is recorded as F-17.

## Learned

- **The ladder's headline result is reliability, and its one variance is a
  path, not an answer.** Three blind sessions produced the same 26 first-shot
  differences by the same four mechanisms at the same counts, and the same
  12/12 final. The only substantive difference is that run 006 needed two
  iterations where 004 and 005 needed one, because its single iteration
  introduced a regression the others did not have (F-12).
- **F-12 is worth more than the iteration it cost.** Rewording `reason` — a
  human-facing string — broke a machine decision that had branched on its text,
  producing the node id `yaml:/`. The fix is to split the code from the message,
  which is exactly what the oracle's own `token: explanation` format does.
- **F-13 is the sharpest new PowerShell hazard.** A single-element `List[T]`
  returned from an `if` expression unrolls to a scalar `string`; indexing that
  yields a `[char]`; the `[char]` misses every string-keyed lookup. Cycle
  detection found nothing at all, terminated normally, and `$children.Count` read
  `1` throughout. The same family bit `verify.ps1` twice more, where
  `(… | Sort-Object -Unique).Count` throws under StrictMode when the result is a
  single item.
- **F-1 recurred a third time and this run found its mechanism.** `Run.Throw`
  without `Run.PassThru` makes `Invoke-Pester` return nothing, so the coverage
  gate compares `0 -lt $null` and never fires, *and* the PreTag guard compares
  `($null + $null) -eq 0` and always fires. One missing line, two dead gates, no
  symptom. The skill's template should carry it.
- **Eight of the ten prior findings recurred.** The two that did not — F-7's
  `.GetNewClosure()` construct and F-9's culture-directory skip — are the two
  that were never about what the plugin fails to say.
- **What went wrong in my own work**, beyond the above: the first `diff.txt` and
  the first-shot compare transcript were both written empty, because
  Compare-Graph writes to the host rather than the pipeline and `Out-String`
  captured nothing; `git clone` into the session scratchpad fails as "Filename
  too long" and needs `core.longpaths`; and a `$root` local silently overwrote
  `$Root` in `verify.ps1`, because PowerShell variable names are case-
  insensitive — the hazard `powershell-module-architect` documents for
  parameters, met in a plain script.
